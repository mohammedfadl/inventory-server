# نظام مراقبة المخزون — حزمة النشر على خادم

**الإصدار:** يُذكر في ملف `VERSION`  ·  **المتطلبات:** Node.js **22.13 أو أحدث** فقط (لا توجد مكتبات تُثبَّت، ولا `npm install`).

## ما الذي تغيّر عن النسخة التي في المتصفح؟
| | نسخة المتصفح | نسخة الخادم |
|---|---|---|
| قاعدة البيانات | IndexedDB في كل جهاز | SQLite واحدة على الخادم (`data/inventory.db`) مشتركة لكل المستخدمين |
| تسجيل الدخول | في المتصفح | على الخادم: كلمات مرور مشفّرة (scrypt)، جلسة بكوكي HttpOnly، قفل 10 دقائق بعد 5 محاولات خاطئة |
| الصلاحيات | واجهة فقط | **تُفرض على الخادم أيضًا**: لا يستطيع مستخدم بلا صلاحية تعديل حفظ بيانات صفحة ما حتى لو تجاوز الواجهة |
| سجل العمليات | — | جدول `audit` (دخول، حفظ، إضافة/تعديل مستخدمين) — يقرأه المدير من `/api/audit` |

## التشغيل المباشر
```bash
unzip inventory-server.zip -d /opt/inventory && cd /opt/inventory
PORT=3000 node server.js
```
افتح `http://عنوان-الخادم:3000` — أول زيارة تعرض شاشة **إنشاء حساب المدير**.

## التشغيل الدائم
* **systemd:** انسخ `inventory.service.example` إلى `/etc/systemd/system/inventory.service` ثم `systemctl enable --now inventory`.
* **Docker:** `docker compose up -d --build` (البيانات في volume باسم `inventory-data`).

## HTTPS (مهم جدًا)
ضع الخادم خلف nginx أو Caddy بشهادة (مثال جاهز: `nginx.conf.example`) واجعل `TRUST_PROXY=1`.
بدون HTTPS تنتقل كلمات المرور كنص عادي على الشبكة.

## المتغيرات
`PORT` (3000) · `HOST` · `DATA_DIR` (data) · `SESSION_HOURS` (12) · `TRUST_PROXY` (1 خلف وسيط) · `MAX_BODY_MB` (300)

## النسخ الاحتياطي
انسخ مجلد `data/` كاملًا (أو أوقف الخدمة وانسخ `inventory.db`). ويمكن للمدير أيضًا استخدام «النسخة الاحتياطية» من داخل النظام.

## نسيت كلمة مرور المدير
```bash
node scripts/reset-admin.js اسم_المدير كلمة_مرور_جديدة_8_أحرف
```

## تحديث النظام بعد كل تطوير
عندما أطوّر النظام أسلّمك ملف `inventory-update.zip` (أو الحزمة كاملة). التحديث العادي:
1. فك الضغط فوق المجلد الحالي **بدون حذف مجلد `data/`** — الملفات المتغيرة هي `public/` و`permissions.json` (وأحيانًا `server.js`).
2. أعد تشغيل الخدمة: `systemctl restart inventory`.

بياناتك ومستخدموك في `data/` لا تتأثر بالتحديث.

## ملاحظات أمنية وتشغيلية
* القراءة: أي مستخدم لديه صلاحية «عرض» لأي صفحة يستطيع قراءة جداول البيانات (لأن الصفحات تتشارك البيانات). الكتابة محكومة بصلاحية «تعديل وتنفيذ» للصفحة المالكة للبيانات.
* التصدير (Excel/PDF) يتم داخل المتصفح بعد وصول البيانات، فمنعه تحكّم واجهة وليس حاجزًا مطلقًا لمن يملك صلاحية العرض.
* إذا عدّل مستخدمان نفس الجدول في وقت واحد، يُرفض حفظ الثاني برسالة «أعد تحميل الصفحة» لمنع الكتابة فوق بيانات الآخر.
* مكتبة Excel تُحمَّل من cdnjs. لشبكة مغلقة: ضع `xlsx.full.min.js` (الإصدار 0.18.5) في المجلد `vendor/` ثم أعد البناء، أو اطلب مني ذلك.
* كل عملية حفظ ترسل الجدول كاملًا؛ مناسب للاستخدام الحالي. مع جداول ضخمة جدًا (مئات آلاف الصفوف) ينبغي مستقبلًا الانتقال لحفظ تفاضلي.
